# Руководство по админке сайта спортивной школы

Этот файл — практическая инструкция для администратора, который раньше не работал с Django-админкой.

## 1) Как зайти в админку

1. Откройте ссылку: `http://localhost:8000/admin/` (или ваш рабочий домен + `/admin/`).
2. Введите логин и пароль администратора.
3. После входа увидите разделы:
   - **Школы**
   - **Контент**
   - **Расписания**

Если логина/пароля нет, попросите разработчика создать пользователя через `createsuperuser`.

---

## 2) Важный принцип перед началом

- Поле **“Опубликован/Опубликовано”** включает/выключает показ на сайте.
- Поле **“Порядок”** управляет сортировкой (меньше число = выше в списке).
- Поле **“URL-имя (slug)”** участвует в ссылках.  
  Если меняете slug у существующей записи, старая ссылка может перестать работать.

---

## 3) Где что редактировать

## Школы

Путь: **Школы → Спортивные школы**

Здесь редактируется карточка школы:
- название, описания;
- фото школы;
- активность и порядок отображения.

Внутри каждой школы (на странице редактирования) есть вложенные блоки:
- **Спортивные объекты** (площадки/залы/бассейны этой школы);
- **Направления подготовки** (секции школы);
- **Документы школы** (включая прейскурант).

### Спортивные объекты

Путь: **Школы → Спортивные объекты**

Что обычно меняют:
- тип объекта (бассейн, зал и т.д.);
- адрес, телефоны, режим работы;
- фото объекта;
- активность и порядок.

### Направления подготовки (секции)

Путь: **Школы → Направления подготовки**

Что важно:
- укажите школу и (желательно) объект;
- возраст “от/до”, описание, фото;
- порядок и активность.

### Тренерский состав

Путь: **Школы → Тренерский состав**

Что заполнять:
- ФИО, фото;
- школа/объект;
- связанные направления (секции);
- достижения, опыт и т.д.;
- активность и порядок.

### Прейскурант

В текущей логике сайта основной способ публикации цен — **документ**.

Путь: **Контент → Документы**  
или внутри карточки школы: **Документы школы**

Для прейскуранта:
1. Создайте/откройте документ.
2. В поле **Тип** выберите **Прейскурант**.
3. Укажите **Школу**.
4. Прикрепите файл в поле **Файл**.
5. Отметьте **Опубликован**.

После этого:
- документ доступен на странице школы;
- из страницы секции работает кнопка “Узнать цену” (если документ прейскуранта у школы есть).

## Контент

### Новости

Путь: **Контент → Новости**

Что заполнять:
- заголовок, URL-имя, текст;
- категория, дата публикации;
- фото/видео (по необходимости);
- флаг “Опубликовано”.

### Галерея (разделы → мероприятия → фото/видео)

Основная работа:
- **Контент → Галерея: мероприятия**

В карточке мероприятия:
1. Укажите название и URL-имя.
2. Выберите **Раздел**: тренировки / соревнования / награждения / видео.
3. Поставьте дату мероприятия и школу (если нужно).
4. Добавьте обложку.
5. В блоке **“Массовая загрузка фото”** можно сразу выбрать много файлов.
6. Сохраните — фото добавятся автоматически.

Также можно править уже загруженные фото/видео прямо в карточке мероприятия
(блок «Уже загруженные фото и видео» внизу страницы).

### Родителям

Путь: **Контент → Информация для родителей**

Для каждого раздела (“справки”, “правила” и т.д.) хранится отдельный текст.

### Соревнования

Путь: **Контент → Соревнования**

Заполняются карточки событий: дата, место, школа, публикация.

### Настройки сайта

Путь: **Контент → Настройки сайта**

Здесь редактируются:
- заголовки и подзаголовок главного баннера;
- главное изображение;
- контакты и ссылки на соцсети.

Обычно запись здесь одна (singleton).

## Расписания

### Ключевая сущность — Период расписания

Путь: **Расписания → Периоды расписания**

Рекомендуемый порядок действий:
1. Создайте период (например, “Сентябрь 2026”).
2. Привяжите к школе/объекту.
3. Укажите даты начала и окончания.
4. Если период должен быть активным — поставьте **Текущий период**.

Важно: при установке “Текущий период” система автоматически снимает этот флаг с другого текущего периода для той же школы/объекта.

### Расписание занятий

Путь: **Расписания → Расписание занятий**  
или внутри карточки периода (вложенный блок).

Заполняются:
- день недели;
- время начала/окончания;
- направление, тренер, объект;
- возрастная группа/группа.

### Сеансы бассейна

Путь: **Расписания → Сеансы бассейна**  
или внутри периода.

Используется для массовых сеансов (детский/взрослый/свободное плавание и т.д.).

### Графики работы объектов

Путь: **Расписания → Графики работы объектов**

Для объекта задаются интервалы:
- общий режим;
- с инструктором;
- перерыв.

Если день недели пустой — запись считается “ежедневно”.

## 4) Быстрые сценарии “как сделать”

### Добавить новую секцию

1. **Школы → Направления подготовки → Добавить**.
2. Выберите школу и объект.
3. Заполните название, возраст, описание.
4. Поставьте “Активно”, задайте “Порядок”.
5. Сохраните.

### Обновить расписание на новый месяц

1. Создайте новый **Период расписания**.
2. Отметьте его как **Текущий период**.
3. Добавьте занятия и сеансы бассейна в этот период.
4. Проверьте страницу “Расписание” на сайте.

### Добавить фото с соревнования

1. **Контент → Галерея: мероприятия**.
2. Откройте мероприятие или создайте новое с разделом “Соревнования”.
3. В “Массовая загрузка фото” выберите сразу все снимки.
4. Сохраните.

### Обновить прейскурант школы

1. **Контент → Документы** (или внутри школы → “Документы школы”).
2. Найдите документ типа “Прейскурант” нужной школы.
3. Замените файл.
4. Убедитесь, что стоит флаг “Опубликован”.
5. Сохраните.

---

## 5) Чеклист перед завершением изменений

Перед тем как считать задачу выполненной:
1. Проверьте, что у записи стоит **Опубликован/Активен**.
2. Проверьте **Порядок** (нет ли случайных одинаковых значений в важных блоках).
3. Откройте сайт и посмотрите нужную страницу:
   - Главная
   - Секции
   - Расписание
   - Галерея
   - Страница школы
4. Убедитесь, что файлы открываются/скачиваются (документы, фото).

---

## 6) Частые ошибки и как исправить

- **“Не вижу запись на сайте”**  
  Проверьте флаг “Опубликован/Активен”.

- **“Показывается старый период расписания”**  
  У нового периода не включен флаг “Текущий период”.

- **“Кнопка цены есть, но файл не скачивается”**  
  У документа типа “Прейскурант” не прикреплен файл или документ не опубликован.

- **“Фото в галерее не там”**  
  Проверьте раздел мероприятия и привязку к нужному мероприятию/школе.

---

## 7) Рекомендуемый рабочий процесс администратора

1. Сначала вносите изменения в контент.
2. Сразу проверяйте результат на публичном сайте.
3. Если что-то массовое (новый месяц, крупное мероприятие) — обновляйте пакетно:
   - сначала период/мероприятие,
   - затем вложенные записи (занятия/фото),
   - потом финальная проверка.

Так меньше шансов забыть важный флаг или поле.
