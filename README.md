# Сайт спортивных школ Елабуги

Веб-сайт для МБУ ДО «СШ «Кама» и других спортивных объектов Елабужского муниципального района.

**Стек:** React (Vite) + Django REST Framework + PostgreSQL

## Структура проекта

```
├── back/          # Django API и админ-панель
├── front/         # React SPA
├── docker-compose.yml
└── README.md
```

## Возможности

### Публичный сайт
- Главная — школы, преимущества, новости
- О школе — документы, лицензии, политики
- Направления подготовки — виды спорта, возраст, прейскурант
- Тренерский состав — по объектам
- Расписание — занятия, сеансы бассейна, график работы (фильтры по школе, объекту, виду спорта)
- Новости, галерея, раздел «Родителям», контакты

### Админ-панель Django (`/admin/`)
- Школы и спортивные объекты (разное расписание для каждой школы/объекта)
- Периоды расписания с привязкой к школе или объекту
- Занятия, сеансы бассейна, графики работы
- Тренеры, направления, прейскурант
- Новости, галерея (загрузка фото), документы
- Настройки сайта

## Быстрый запуск (Docker)

Требуется: [Docker Desktop](https://www.docker.com/products/docker-desktop/)

```bash
docker compose up --build
```

После запуска:
- **Сайт:** http://localhost
- **API:** http://localhost:8000/api/
- **Админка:** http://localhost:8000/admin/

Создайте суперпользователя:

```bash
docker compose exec backend python manage.py createsuperuser
```

Начальные данные (школы, объекты, прейскурант) загружаются автоматически командой `seed_data`.

## Локальная разработка без Docker

### Backend

```bash
cd back
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
copy .env.example .env
```

Для разработки без PostgreSQL в `.env` установите:

```
USE_SQLITE=true
```

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py seed_data
python manage.py createsuperuser
python manage.py runserver
```

### Frontend

```bash
cd front
npm install
npm run dev
```

Сайт: http://localhost:5173 (прокси на API :8000)

## База данных

**PostgreSQL 16** — для продакшена и Docker. Подходит для хранения расписаний, медиафайлов и связей между школами/объектами.

Для локальной разработки можно использовать SQLite (`USE_SQLITE=true`).

## Цветовая схема

Синий `#1a4b8c`, красный `#d62828`, белый — спортивная тематика.

## Управление расписанием

1. В админке создайте **Период расписания** для нужной школы или объекта.
2. Отметьте «Текущий период» для активного расписания.
3. Добавьте **Занятия** и **Сеансы бассейна** внутри периода или отдельно.
4. Для тренажёрных залов используйте **Графики работы объектов**.

Разные школы и объекты могут иметь независимые периоды и расписания.

## Загрузка фото

- Галерея: **Контент → Фото галереи**
- Тренеры: **Школы → Тренеры**
- Новости: **Контент → Новости**
- Объекты: **Школы → Спортивные объекты**

Файлы сохраняются в `back/media/` (в Docker — volume `media_data`).
